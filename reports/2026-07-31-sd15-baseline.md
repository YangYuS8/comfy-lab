## 已知限制与下一步

- API 访问依赖当前 Fedora 内网地址和正在运行的服务；该地址是环境配置，不硬编码进工作流或提交内容。
- 此基线使用的模型是旧版 SD 1.5，适合验证 API 可复现链路，不作为现代高质量工作流的质量基准。
- 每次复现应保留工作流与本报告所列参数；只改动明确记录的 `--set` 覆盖项。
- 后续实验应单独记录变量、输出和报告；不要污染这条基线或提交生成图像。
